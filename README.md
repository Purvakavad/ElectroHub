# ElectroHub

A modern and responsive e-commerce website built using HTML, CSS, and JavaScript.

* Responsive Design
* Modern User Interface
* Product Categories

* Shopping Cart UI
* Search Bar
* Mobile-Friendly Layout
* Clean Navigation

* JavaScript
